# monorepo

Monorepo used to demo Socket: the Registry Firewall and pull request scanning.

| Folder    | Ecosystem | Manifest            |
|-----------|-----------|---------------------|
| `npm/`    | npm       | `package.json`      |
| `python/` | PyPI      | `requirements.txt`  |
| `maven/`  | Maven     | `pom.xml`           |
| `go/`     | Go modules| `go.mod`            |

Demo pull requests are opened by `pr.sh` from the demo kit (branches named `demo/...`).
